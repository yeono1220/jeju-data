# 데이터올레 (DataOlle)

> **웹 시연판** https://jeju-data-impgzzzsb3cey9napjmbql.streamlit.app/ — 무료 호스팅이라 한동안 접속이 없으면 서버가 잠듭니다. 잠들어 있으면 깨우기 버튼이 뜨고, 누르면 30초 안에 열립니다.
> 소개 페이지: https://yeono1220.github.io/jeju-data/

**탐나는전 캐시백 설계 에이전트 — "예산 400억이면 몇 %로 해야 연말까지 안 끊기고 전통시장 몫이 늘까?"에 숫자로 답하고, 바로 쓸 문서까지 만듭니다**
「제주 AI·빅데이터 활용 AI Agent 개발 챌린지」 출품작

제주빅데이터센터에만 있는 탐나는전 결제 데이터(1-32)에 카드 소비·거주인구·날씨를 동네(행정동) 단위로 묶어 다음 순서로 일합니다.

1. **진단** — 업종·동네·전통시장 쏠림, 원도심 상권, 고령화·학령인구, 도민 소비 대비 탐나는전이 덜 쓰이는 사각지대
2. **효과 추정** — 적립률이 바뀐 달(예: 2025년 4~6월 15%)을 작년 같은 달과 비교하는 자연실험으로 **적립률 1%p당 사용액 반응**을 잽니다.
   학원비 선결제처럼 **시기만 앞당긴 소비**를 바로 뒤 두 달의 빈자리로 찾아 걷어 내고, 추정에 쓰지 않은 달로 **백테스트**합니다.
3. **설계(시뮬레이션)** — 같은 예산으로 A 현행·B 균등·C 동네 살리기 집중·D 사각지대 보강·**E 쏠림 방지(건당 적립 상한, 학원·교육은 기본률만)** 안을
   돌려 **예산 소진일, 전통시장·원도심 몫, 학원·교육 몫, 고령 동네 1인당 적립액(역진성)**을 비교하고 추천안을 고릅니다.
4. **실행물** — 도청 개선안 초안·대안 비교표·상인회 안내문·현수막/SNS/문자 문구·어르신 안내문·추진 일정(PDF·DOCX)
5. **효과 확인** — 시행 뒤 붙여 넣을 질문을 주고, 다음 방문 때 전후 효과로 다음 배분(C′안)을 다시 계산합니다.

반출 기준(10 미만 비공개·역산 방지)을 지킨 보고서와 반출 신청 서류까지 만들며, **AI는 숫자도, 센터 데이터에서 나온 이름·문장도 보지 않습니다**(아래 안전장치).

| 기능 | 대상 | 결과물 |
|---|---|---|
| **에이전트에게 맡기기** | 누구나 | 질문 → 데이터 확인 → 진단·효과 추정·설계 → 실행물 묶음 → 4단계 답(진단·처방·실행물·효과 확인)과 다음 할 일. Claude 도구 사용, AI가 없으면 규칙 기반으로 같은 순서 |
| **탐나는전 캐시백 설계** (대표) | 도청·행정시·주민센터·상인회 | 동네 진단 카드, 사용 규모·전통시장·오일장 장날 효과, 침투지수·사각지대, 원도심·신도심 상권, 인구 구조·학령인구 경보, 비 오는 날 효과, **효과 추정(반응도·앞당긴 소비·백테스트)**, **처방 설계(A~E·C′, 소진일·혜택 행선지·역진성·민감도)**, 보고 문단 |
| **실행물 묶음** | 도청·주민센터·상인회 | 한 장 요약, 도청 개선안 초안(월별 적립 계획), 대안 비교표, 상인회 안내문, 홍보 문구, 어르신 안내문, 추진 일정·체크리스트, 효과 확인 질문 |
| 사건·정책 전후 효과 | 연구자·담당자 | 매칭 비교 지역 + 이중차분 효과, 공간 위약 검정, 사전 추세, 논문·보고용 문단 |
| 동네 현황자료 · 창업 시장분석 · 자유 질문 | 기관·소상공인·누구나 | 엔진을 함께 쓰는 보조 코스 |

## 빠른 시작 (Windows 10/11 64bit)
1. 압축을 짧은 경로(예: `C:\dataolle`)에 풉니다.
2. [Python 3.13.17 Windows installer (64-bit)](https://www.python.org/downloads/windows/)를 설치합니다("Add python.exe to PATH" 체크).
3. `설치.bat` 더블클릭(처음 한 번, 5~10분) → `실행.bat` 더블클릭 → 브라우저에 `http://127.0.0.1:8501`이 열립니다.
   - 설치 끝에 **설치 점검**이 자동으로 돕니다(`점검.bat`으로 다시 실행 가능). 센터 PC처럼 서명 없는 확장 모듈(.pyd·.dll)을 막는 환경에서 `[차단]`이 나오면 `data\점검결과.txt`의 폴더·파일 목록으로 허용 등록을 요청합니다(설치 매뉴얼 3-1절).
4. 센터 데이터가 없으면 처음 화면의 **가상데이터로 바로 체험하기** 버튼(또는 **② 데이터 → 가상데이터 만들고 불러오기**)으로 바로 체험할 수 있습니다(처음 한 번 1~2분).
5. **① 질문**에서 예시를 누르고 **에이전트에게 맡기기**. 예:
   - "예산 400억 원으로 탐나는전 적립을 1년 내내 이어 가려면 어떻게 나눠야 해요?"
   - "2025년 2분기 15% 적립 때 늘어난 사용액 중 학원 선결제 같은 앞당긴 소비는 얼마나 돼요?"
   - "일도1동, 탐나는전으로 동네를 살릴 수 있을까요?"

자세한 내용은 `docs/설치_매뉴얼.pdf`, `docs/사용자_매뉴얼.pdf`를 보세요.

## 안전장치 요약
- **숫자도 이름도 보지 않는 에이전트(레벨 0, 기본)**: AI(기본 Claude Haiku 5.5)에는 질문(수치 가림), 데이터·지표 이름, 절 제목, 사실 번호만 갑니다.
  센터 데이터를 조회해서 나온 **동네·시장·업종 이름, 순위 항목, 추천안·판정, 방향 단어가 든 초안 문장**은 `{{t3}}` 토큰으로 가려 보내고(`ai/redact.py`),
  돌아온 답의 토큰·`{{f12}}` 자리표시자는 이 PC에서 채웁니다. 근거 없는 숫자가 하나라도 있으면 답을 버리고 규칙 기반 답을 씁니다.
- **입력 가드레일**(`ai/guardrails.py`): 원본을 그대로 달라는 요청, 개인·개별 가게를 가려 달라는 요청, 지시를 무시하라는 요청, 센터 데이터로 답할 수 없는 범위 밖 질문은 AI를 부르기 전에 이 PC에서 막고 가능한 분석을 안내합니다.
- **반출 검수 엔진**: 단순집계의 10 미만 칸 비공개(1차) + 합계로 다시 계산되는 칸을 행렬 영공간 검사로 찾아 최소 칸만 추가로 가림(2차), 필요하면 범주처리.
- **질문 속 예산·기간은 이 PC가 읽음**: '400억 원' 같은 숫자는 AI에 [수치]로 가려 보내고, 시뮬레이션에는 질문 원문에서 이 PC가 읽은 값을 씁니다.
- **AI 없이도 끝까지**: AI 호출이 실패하거나 센터 보안 정책으로 막혀도 같은 도구를 규칙 기반 순서로 돌려 같은 결과물을 만듭니다.
- **결과 삭제 ON/OFF**: 세션별 작업 폴더(`data\sessions\…`)에만 저장하고, `작업 끝내기`로 통째 삭제. 자동 삭제 ON이면 다음 실행 때 오래된 세션도 지웁니다.
- **반출 신청 도우미**: PDF·PNG만 모으고(텍스트·엑셀 차단), 활용 사유·설명란 문구·표/그림별 점검표 PDF를 자동 작성합니다.
- **감사 로그**: 외부로 보낸 내용과 가린 토큰 수를 원문 그대로 남깁니다(관리자 탭).

```
  spec/       센터 데이터 명세서 v13(71종) 레지스트리·코드표

  analysis/   시맨틱 레이어(지표·차원) → SQL(DuckDB) → 집계·검수·응용집계·사실(fact)

              · response(반응도 추정·앞당긴 소비·백테스트) · policy(적립 예산 배분 시뮬레이터 A~E·C′)
              · action_pack(실행물 묶음) · before_after(전후 효과) · status(현황) · market(창업)
  ai/         에이전트(도구 사용 루프·규칙 기반), 레벨 0 가림막(redact), LLM 연결(urllib), 전송 게이트웨이·감사 로그, 계획기, 숫자 검증
  app/        화면(Streamlit, 127.0.0.1 전용)
  synth/      가상 센터 CSV 생성기(시연·검증용, 실제 데이터 아님 — 정답 반응·학원 선결제를 심어 둠)
tests/        단위·통합 테스트(반출 역산 공격, 숫자·이름 누수 검사, 심어 둔 반응·선결제 복원, 예산 배분, 실행물, 에이전트 연쇄 등)
```

## 개발
```
python -m pip install -r requirements-lock.txt pytest
set PYTHONPATH=src                    # (리눅스·맥: export PYTHONPATH=src)
python -m pytest                      # 테스트
python -m dataolle.synth.generator ./요청파일 --profile demo    # 가상데이터(탐나는전 2023.1~2025.9 포함)
python -m streamlit run src/dataolle/app/main.py
python tools/public_usage_check.py    # 공개 월별 사용액으로 반응 크기 대조
```

## 데이터·저작권 유의
- 가상데이터는 센터 CSV 형식만 재현한 **시연용 가짜 데이터**이며, 모든 결과물에 표시됩니다.
- 적립률 이력은 보도로 확인한 값입니다(`courses/rates.py`, 출처 표기). 공식 이력이 있으면 `data\rates.csv`(열: ym,rate,limit,source)로 바꿔 넣습니다.
- **공개 실데이터**: 행정안전부 주민등록 인구통계(2026년 10월, 제주 읍면동 43곳의 총인구·65세 이상·0~14세 발췌, `src/dataolle/spec/data/public_pop.json`)를 고령 동네 판정과 1인당 적립액 계산에 씁니다. 새 달 자료는 jumin.mois.go.kr에서 엑셀을 받아 `python tools/build_public_pop.py <엑셀>`로 바꿉니다.
- 센터 원본 CSV, API 키, DAKER 제공 「제주데이터허브 데이터목록」 파일은 이 저장소·압축 파일에 넣지 않습니다.
- 센터 데이터 명세서(공개 자료)를 바탕으로 데이터셋 구조를 정의했습니다.
