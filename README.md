# 데이터올레 — 웹 시연판 (`web` 브랜치)

제출본(`main` 브랜치)과 **같은 코드**로 돌아가지만, 무료 호스팅에서 돌도록 무거운 부분만 미리 끝내 둔 판입니다.

|  | 설치형 본체(`main`) | 웹 시연판(`web`) |
|---|---|---|
| 데이터 | 센터 CSV 또는 가상데이터 693MB를 적재 | 미리 계산한 결과(`webdata/result.json`, 47KB) |
| 숫자 계산 | 이 PC의 DuckDB | 미리 계산해 둔 사실 131개 — **값은 같음** |
| AI 답 작성 | 실제 호출 | **실제 호출** (같은 프롬프트·같은 검증) |
| 질문 | 자유롭게 | 미리 계산해 둔 두 가지(제주 전체 / 일도1동) |

자료를 올리는 데 1.6GB가 드는데 무료 서버는 1GB까지만 줍니다. 사무용 PC는 보통 8~16GB라 설치하면 그대로 돌아갑니다. 여기서는 미리 돌려 둔 결과를 싣고, 숫자는 그때 실제로 나온 값 그대로입니다.

## AI 호출이 진짜인 이유

본체와 같은 계약을 그대로 씁니다.

- AI에게는 사실의 **설명과 번호만** 보냅니다. 전송 레벨 0이라 **센터 수치는 0건** 나갑니다.
- AI는 답에 숫자를 쓰지 못하고 `{{f12}}` 자리표시자만 씁니다. 값은 서버가 채웁니다.
- 사실 목록에 없는 숫자가 답에 있으면 그 답을 **버리고** 규칙 기반 답으로 바꿉니다(`verify`).

## 배포

Streamlit Community Cloud에서 이 브랜치의 `webapp.py`를 지정하고, Secrets에 키를 넣습니다.

```toml
ANTHROPIC_API_KEY = "sk-ant-..."
```

키를 넣지 않아도 규칙 기반으로 똑같이 동작합니다. 키 보호를 위해 한 사람당 3회, 하루 300회로 호출을 제한합니다.
